# mi_reporte_2

Aquí voy documentando lo que tenemos que hacer

Para esta versión muy básica solo necesitaremos crear 3 archivos:

1. Archivo de configuración de QUARTO que forzosamente se tiene que llamar "_quarto.yml"
2. Archivo QUARTO (.qmd) donde pondremos el contenido de nuestro reporte. Que debe llamarse "index.qmd"
3. Archivo de configuración de una acción de GitHub que le da instrucciones para renderear nuestro sitio

Adicionalmente "picaremos" unos botones en GitHub para que la magia suceda.

+ Paso: Crear archivo "_quarto.yml"
+ Paso 2: Crear el archivo "index.qmd"
+ Paso 3: Picar botones en GitHyub. Settings -> Pages -> GitHub Actions
